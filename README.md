# AI Call Agent Project

The full codebase and architecture documentation are located in the [`ai-call-agent/`](file:///d:/minior%20projct%20gbu/ai-call-agent) directory.

## Monorepo Layout

- **[`ai-call-agent/backend/`](file:///d:/minior%20projct%20gbu/ai-call-agent/backend)**: FastAPI Python backend with SQLAlchemy models, Alembic migrations, mock adapters, and pytest test suite.
- **[`ai-call-agent/frontend/`](file:///d:/minior%20projct%20gbu/ai-call-agent/frontend)**: Next.js 15 App Router dashboard with live call simulation, spam review queue, analytics, and settings.
- **[`ai-call-agent/docs/`](file:///d:/minior%20projct%20gbu/ai-call-agent/docs)**: Complete architecture, call flows, API contracts, database schema, security governance, deployment runbook, and ADRs.

Please refer to [`ai-call-agent/README.md`](file:///d:/minior%20projct%20gbu/ai-call-agent/README.md) for complete instructions.
